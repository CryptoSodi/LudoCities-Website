FAQ

Common Questions

What is Ludo Cities?

Ludo Cities is the first Web3 Ludo game built on the Solana blockchain. Players can play the classic Ludo board game against real opponents, earn $LUDC cryptocurrency rewards for winning, and own their in-game assets as Solana NFTs.

How do I earn $LUDC tokens?

You earn $LUDC by winning multiplayer matches, completing daily challenges, and finishing on the leaderboard. The more you play and win, the more you earn. $LUDC is a live Solana token that can be traded on DEXs.

Do I need crypto to start playing?

No. You can download Ludo Cities on Android and start playing for free without any wallet or crypto. You only need a Solana wallet when you're ready to earn, stake, or collect NFTs.

What are the Ludo Cities NFTs?

Ludo Cities NFTs are unique digital game assets on the Solana blockchain — including token designs, board skins, and upcoming city land parcels. Each NFT provides in-game perks and can be freely traded on NFT marketplaces like Magic Eden.

Which platforms is the game available on?

Ludo Cities is currently live on Android. iOS, Web browser, and console versions are on the roadmap for 2026. All versions share the same blockchain economy.
